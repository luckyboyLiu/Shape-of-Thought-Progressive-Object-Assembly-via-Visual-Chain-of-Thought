## 如何查看仓库里的 PNG 图片

仓库根目录下的 `Overview` 文件本身就是 PNG 图片（只是文件名没有 `.png` 后缀）。

- 在 GitHub 网页中直接点击 `Overview` 文件即可查看大图
- 本地查看可使用：
  - Linux: `xdg-open Overview`
  - macOS: `open Overview`
  - Windows: `start Overview`
